## Setup

1. Open the React app directory:
   
```bash 
cd deber2
```

2. Install dependencies:

```bash 
npm install
```

3. Create your own `.env` file inside `deber2/` with your WeatherAPI key:

```env
VITE_WEATHERAPI_KEY=your_api_key_here
```

You can copy the example from `.env.example`

4. Run locally:

```bash
npm run build
npm run dev
```
